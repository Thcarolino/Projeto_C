# Projeto_C

## Sistema de Estacionamento em C#

Projeto desenvolvido para praticar os fundamentos da linguagem C# e os conceitos de Programação Orientada a Objetos (POO).

## Exercícios desenvolvidos no TP2

- Exercício 1 — Normalização de placas.
- Exercício 2 — Formatação de resumo diário de tickets.
- Exercício 3 — Validação de placas no padrão Mercosul.
- Exercício 4 — Classes, objetos e construtores.
- Exercício 5 — Encapsulamento e validação de propriedades.
- Exercício 6 — Records e imutabilidade.

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio Code
- Git e GitHub

## Conceitos aplicados

- Classes e objetos
- Métodos reutilizáveis
- Interpolação de strings
- Namespaces
- Sobrecarga de construtores
- Encapsulamento
- Getters e setters
- Records e imutabilidade

## Como executar

Acesse a pasta do exercício desejado pelo terminal e execute o comando:

`dotnet run`

obs.: A partir deste TP, decidi por manter os próximos TPs numa mesma pasta a fim de deixar o meu projeto mais organizado.
